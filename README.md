# Nut (Android)

เบราว์เซอร์เรียบง่าย สไตล์ Apple สำหรับ Android

- ท่องเว็บด้วย WebView มีหน้าเริ่มต้นและช่องค้นหาด้านล่าง
- ปุ่ม **ย้อน 10 วินาที / ข้าม 10 วินาที** อยู่มุมล่างซ้าย แสดงเมื่อหน้าเว็บมีวิดีโอ (และตอนดูเต็มจอ)
- **แยกจอ 2 / 3 / 4** ทั้งแนวตั้งและแนวนอน ปุ่ม ⊞ เลือกจำนวนจอ ปุ่ม ⇄ สลับรูปแบบการวาง
  แตะช่องไหนช่องนั้นจะเป็นช่องที่ใช้งาน (ขอบสีน้ำเงิน) แถบที่อยู่เว็บจะโหลดในช่องนั้น

## วิธีได้ไฟล์ APK

### ทางที่ 1: ให้ GitHub build ให้ (ไม่ต้องติดตั้งอะไร)
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. เปิดแท็บ **Actions** → **Build APK** → รอจนเสร็จ
3. ดาวน์โหลด `nut-debug-apk` ได้จากหน้าผลการรัน แล้วแตก zip จะได้ `app-debug.apk`
4. ส่งไฟล์เข้ามือถือ แล้วเปิดเพื่อติดตั้ง (ต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

### ทางที่ 2: Android Studio
เปิดโฟลเดอร์นี้ใน Android Studio → Build → Build APK(s)

## ข้อจำกัดที่ควรรู้
- ปุ่มข้าม 10 วินาทีควบคุมตัวเล่น `<video>` ในหน้าเว็บ (รวม iframe ที่โดเมนเดียวกัน)
  เว็บที่ฝังตัวเล่นจากโดเมนอื่นใน iframe จะสั่งงานไม่ได้ เพราะเบราว์เซอร์กันไว้
- ไฟล์ที่ build ออกมาเป็น debug APK สำหรับทดสอบ ถ้าจะลง Play Store ต้อง build แบบ release และเซ็นชื่อแอป
